**Test build.** For testers: if you have 0.3.5-test.1 or test.2, Klipp offers this one by itself. Otherwise download [Klipp-Setup.exe](https://github.com/alonsy/klipp/releases/download/v0.3.5-test.3/Klipp-Setup.exe) and run it over your Klipp. Not a normal release yet; most people should stay on [the latest release](https://github.com/alonsy/klipp/releases/latest).

> Windows may say it protected your PC, because the installer isn't signed yet. Click **More info**, then **Run anyway**.

### New

- **Test builds install themselves.** From this build on, when a new test build is out, Klipp installs it once no game has been in front for a few minutes and no clip is being saved, without opening its window. Recording restarts, so the replay buffer starts over. Settings → About → Updates can turn it off.

### Testing

- **Updating can't get stuck on a running Klipp.** The installer now closes Klipp without asking, the window first and then the recorder, and waits until Windows lets go of both programs instead of a fixed moment. If something still holds one, it's closed too, and as a last resort the old program is moved aside so the new one always gets written. Before, a quiet update could skip a program it couldn't replace and leave the old one running under the new version number.
- **Updates are logged.** The installer and the updater write each step to `install.log` next to Klipp's log, and the recorder adds it to its log on its next start, so a stuck or failed update shows up without asking you about it.
