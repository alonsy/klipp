**Test build.** For testers: if you have 0.3.5-test.1, Klipp offers this one by itself. Otherwise download [Klipp-Setup.exe](https://github.com/alonsy/klipp/releases/download/v0.3.5-test.2/Klipp-Setup.exe) and run it over your Klipp. Not a normal release yet; most people should stay on [the latest release](https://github.com/alonsy/klipp/releases/latest).

> Windows may say it protected your PC, because the installer isn't signed yet. Click **More info**, then **Run anyway**.

### Testing

- **Full frame rate on fast screens.** On a 144 or 165 Hz screen, Windows handed Klipp only about 34 pictures a second at 60 fps, so clips looked choppy even with nothing late. Klipp now asks for pictures twice as often as it records them.
- **AMD graphics cards keep up in games.** Klipp let the AMD encoder work on only two frames at a time, so each frame waited for the one before it (13 of every 17 ms on an RX 6650 XT). It now has four in flight, as on NVIDIA cards.
- **Klipp checks your graphics card after an update.** The first time a new version starts, it records a few seconds at your video settings before it starts the buffer. If they don't run smoothly on your PC, it picks the best lighter setting that does and tells you in the Klipp window. It waits for the next start if a game is keeping the card busy.
- **Setup measures your card.** It records a few seconds at each candidate setting and preselects the best one that leaves plenty of room for a game.
- **Klipp remembers when a game was too much.** If the card couldn't keep up in two sessions, Klipp starts at the lower frame rate from then on instead of stuttering at the start of every match. Each new version and new video settings try the set rate again.

### New

- **League of Legends auto-clips.** Double kills up to pentakills (counted the game's way), first blood, steals and team aces become clips by themselves; objectives, assists and the result are marked in them. Klipp asks the game's own Live Client Data API on your PC while you play, so there's nothing to install. Choose what counts in Settings → Auto-clips.
- **Rocket League auto-clips.** Goals, epic saves and demolitions become clips; saves and assists can be turned on; the result is marked. Klipp uses Psyonix's Stats API and turns it on in Rocket League's `TAStatsAPI.ini` (only that setting changes), so **restart Rocket League once** after Klipp's first start.
- Both are new: if a clip is missing or a moment is named wrong, say which game and roughly when, and the log will show what the game reported.

- **Update checks go through klipp.dev.** Klipp sends the version you have and a random install number, nothing else, so the developer can see how many copies are in use. Settings → About → Updates can turn checks off. If klipp.dev can't be reached, Klipp asks GitHub as before.
- **More in the log** for test builds: your Windows version, processor, memory, graphics cards and driver, screens, the main settings, and once a minute which game is in front and how busy the graphics card is.
