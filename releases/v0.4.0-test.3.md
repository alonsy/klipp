**Test build.** For testers: Klipp installs this one by itself between games, or offers it on older test builds. Otherwise download [Klipp-Setup.exe](https://github.com/alonsy/klipp/releases/download/v0.4.0-test.3/Klipp-Setup.exe) and run it over your Klipp. Not a normal release yet; most people should stay on [the latest release](https://github.com/alonsy/klipp/releases/latest).

> Windows may say it protected your PC, because the installer isn't signed yet. Click **More info**, then **Run anyway**.

### Fixed

- **The save key works in League of Legends matches.** Some games keep other apps' shortcut keys to themselves while they're in front, and League does during a match, so the save key did nothing there. Klipp now also listens for the key another way and saves even when Windows doesn't pass it on. It only listens: no key is blocked or slowed down.
