# Code of conduct

Klipp is made for players, by players. Keep it a place where anyone can ask a question, report a bug or send a pull request without feeling stupid for it.

- **Be kind.** Disagree with ideas, not people. Assume good intent; most people are trying to help.
- **Stay on topic.** Issues and pull requests are about Klipp.
- **No harassment.** No insults, slurs, personal attacks, sexual content, or sharing someone's private information.
- **Don't ask for cheats.** Klipp doesn't read game memory, inject into games or give anyone an advantage, and won't help anyone do so.

Comments that break these rules are edited or removed, and people who keep breaking them are blocked from the repository.

To report something privately, use [klipp.dev/feedback](https://klipp.dev/feedback) and leave an email address if you want an answer.
